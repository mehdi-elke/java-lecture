# Le TP

Le TP est le fil rouge des quatre séances : c'est **🔗 [ShortLink](shortlink/enonce/00-presentation.md)**, un raccourcisseur de liens, guidé pas à pas.

Pour ceux qui ont déjà de l'expérience et veulent travailler en autonomie, un **parcours autonome 🟣** est proposé à la place : **🗄️ [Mini-Redis](miniredis/enonce/00-presentation.md)**. L'enseignant aide en priorité sur ShortLink : sur Mini-Redis, vous avancez seuls avec ses outils (`Compare`, la spécification). Le choix se fait en séance 1, et il est définitif.

| | 🔗 [ShortLink](shortlink/enonce/00-presentation.md) | 🗄️ [Mini-Redis](miniredis/enonce/00-presentation.md) |
|---|---|---|
| Le projet | un raccourcisseur de liens, comme bit.ly | un serveur compatible Redis, utilisable avec `valkey-cli` |
| Ce qu'on vise | faire passer des tests fournis, puis en écrire à soi | répondre exactement comme le vrai serveur, Valkey |
| Guidage | pas à pas, avec le début du code à chaque exercice | des objectifs, à vous de trouver comment |
| Installation | Java 25 et Maven | Java 25 et Maven (Docker facultatif) |
| Pour qui | tout le monde | vous programmez déjà à l'aise et voulez chercher seuls |

Les deux couvrent **les mêmes notions**, séance par séance, et sont **évalués de la même façon** : QCM, rendus sur GitHub vérifiés par des tests de correction, et deux passages de 3 minutes pour expliquer et modifier votre code.

**Vous hésitez ? Prenez ShortLink.** Un TP terminé et bien compris vaut mieux qu'un TP ambitieux à moitié fait. Et si ShortLink vous paraît trop simple, ses exercices 🔵 et 🟣 vous occuperont ; vous pouvez aussi écrire vos propres tests avant d'activer ceux qui sont fournis.
