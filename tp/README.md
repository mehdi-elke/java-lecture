# Le TP : deux sujets au choix

Le TP est le fil rouge des quatre séances. Vous choisissez **un** des deux sujets en séance 1, et vous le gardez jusqu'au bout.

| | 🔗 [ShortLink](shortlink/enonce/00-presentation.md) | 🗄️ [Mini-Redis](miniredis/enonce/00-presentation.md) |
|---|---|---|
| Le projet | un raccourcisseur de liens, comme bit.ly | un serveur compatible Redis, utilisable avec `valkey-cli` |
| Ce qu'on vise | faire passer des tests fournis, puis en écrire à soi | répondre exactement comme le vrai serveur, Valkey |
| Guidage | pas à pas, avec le début du code à chaque exercice | des objectifs, à vous de trouver comment |
| Installation | Java 25 et Maven | Java 25, Maven, et Docker (ou Valkey) conseillé |
| Pour qui | vous découvrez Java, ou la programmation vous demande encore des efforts | vous programmez déjà à l'aise et voulez un défi |

Les deux sujets couvrent **les mêmes notions**, séance par séance, et sont **évalués de la même façon** : QCM, rendus sur GitHub vérifiés par des tests de correction, et deux passages de 3 minutes pour expliquer et modifier votre code.

**Vous hésitez ? Prenez ShortLink.** Un TP terminé et bien compris vaut mieux qu'un TP ambitieux à moitié fait. Et si ShortLink vous paraît trop simple, ses exercices 🔵 et 🟣 vous occuperont.
